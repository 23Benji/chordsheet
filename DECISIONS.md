# Decisions

| 2026-11-02 | Chord transposition uses our own `core/transpose.ts`; chordsheetjs is used only for parsing. | chordsheetjs' `Chord.transpose()` keeps the source accidental and yields spellings like `E#m`, `B#`, `Fb`. Ours spells every note from a sharp or flat table chosen by the target key (flat keys: F Bb Eb Ab Db Gb, Dm Gm Cm Fm Bbm Ebm), with `preferSharps` overriding. Chords are left exactly as written when transpose and capo are both 0. |
| 2026-11-02 | Backslashes in song text are swapped for a placeholder before parsing and restored afterwards. | chordsheetjs treats `\` as an escape character and failed on songs 007 and 126 (`D\ Degno è…`). Song files must not be modified. |
| 2026-11-02 | Header with capo: "Tonalità" shows the key of the chords on screen (shapes); "(originale X)" appears when the sounding key differs from the original; "Capo 2 · suona in A" shows the sounding key. | SPEC shows both labels but doesn't say which key "Tonalità" refers to when a capo is set.
