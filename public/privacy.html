Chordsheet — Informativa sulla privacy

Ultimo aggiornamento: 5 novembre 2026

Chordsheet è un canzoniere (accordi e testi, scalette, note personali) che funziona nel browser e può essere installato come app. Non ha un server proprio, non contiene pubblicità e non raccoglie statistiche.

I tuoi dati restano sul tuo dispositivo

Canti, note, scalette, cartelle e impostazioni sono salvati solo nella memoria del browser del tuo dispositivo. Lo sviluppatore non li riceve e non può vederli.

Sincronizzazione con Google Drive (facoltativa)

Se scegli “Accedi con Google” per sincronizzare i tuoi dispositivi:

  • l'app salva un file con canti, note, scalette e cartelle nella cartella nascosta dell'app del tuo Google Drive (autorizzazione drive.appdata). L'app non può vedere gli altri file del tuo Drive;
  • l'app legge il tuo indirizzo e-mail solo per mostrarti con quale account sei collegato;
  • l'autorizzazione di accesso resta sul tuo dispositivo; i dati passano direttamente tra il tuo dispositivo e Google, senza server intermedi;
  • nessun dato viene inviato allo sviluppatore o a terzi, venduto o usato per pubblicità.

L'uso e il trasferimento delle informazioni ricevute dalle API di Google rispettano le Google API Services User Data Policy, inclusi i requisiti di uso limitato (Limited Use).

Smettere di sincronizzare ed eliminare i dati

  • In Chordsheet: Impostazioni → Sincronizzazione → “Esci da Google su questo dispositivo”.
  • Per eliminare il file da Google Drive: Google Drive sul web → Impostazioni → Gestisci app → Chordsheet → Opzioni → “Elimina i dati nascosti dell'app”.
  • Per togliere l'accesso all'app: myaccount.google.com/permissions.
  • I dati sul dispositivo si cancellano eliminando l'app o i dati del sito dal browser.
